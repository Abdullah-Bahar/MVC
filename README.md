# :rocket: BTK Akademi - ASP.NET Core MVC

## :bulb: Proje Hakkında

Bu repo, BTK Akademi bünyesinde verilen ASP.NET Core MVC eğitimi boyunca üzerinde çalıştığım bir repodur.

Bu eğitim kapsamında çalışırken edindiğim bilgileri yorum satırları aracılığı ile kod içerisine gömmüş bulunmaktayım. 

Bu proje üzerinde çalışırken yapılan değişiklikleri commit atarken commit mesajlarına özen gösterip nerede ne yapıldığını açıkça ifade etmeye çalıştım.

**NOT:** Eğitimde .NET 6.0 kullanılmıştır. Ancak bu proje .NET 8.0 ile geliştirilmiştir. Ve ona göre modernize edilmiştir.

- :link: [Eğitimin Orijinal Reposu](https://github.com/zcomert/btk-akademi-aspnet-core-mvc-egitimi)
